# Start a new requirement

1. Read **docs/workflow/WORKFLOW_CHECKLIST.md** for order and gates.
2. Do **steps 1–3** (requirement doc → §3 test plan) **first**, then step 4 (development). Detail: `docs/workflow/DEVELOPMENT_WORKFLOW.md`.
3. If there is a current requirement, use that doc; otherwise create `docs/requirements/yyyyMMdd-name.md`. Template: `docs/template/REQUIREMENT_TEMPLATE.md`.
4. **Agent collaboration**: Follow **docs/workflow/AGENT-COLLABORATION-ON-REQUIREMENT.md**. Sequence: **Requirements** → **Security** (if PII/decrypt/access) → **Contract** / **DBA** / **Architecture** / **Consistency** / **UX** (as needed) → **Backend/Frontend/DB** → **Review** (optional) → **QA** → **Documentation** / **Release** (as needed). **Role boundaries** (no duplication): **docs/workflow/CURSOR-SUBAGENTS-DESIGN.md** §2.6.
