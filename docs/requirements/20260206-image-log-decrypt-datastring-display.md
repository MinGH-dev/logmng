# 20260206 - Image Log 복호화 시 datastring 필드 표시 문제

## 1. 사용자 요건 내용

### 요건 설명
복호화 요청 시 `datastring` 필드의 데이터가 복호화된 값으로 변환되지 않고 원본 암호화된 값이 그대로 표시되는 문제가 발생했습니다.

### 사용자 시나리오
1. 사용자가 로그인합니다
2. Image Log 검색 화면으로 이동합니다
3. 검색 결과에서 복호화 버튼을 클릭합니다
4. **문제**: `datastring` 필드에 복호화된 값이 표시되지 않고 원본 암호화된 값이 그대로 표시됩니다

### 기대 결과
- 복호화 버튼 클릭 시 `datastring` 필드에 복호화된 값이 표시되어야 합니다
- 복호화된 값에서도 키워드 하이라이트가 정상적으로 동작해야 합니다
- 상세 보기 모달에서도 복호화된 값이 표시되어야 합니다

2. **상세 보기 모달 문제**: 상세 보기 모달에서 복호화된 값을 표시하지 않음

- 상세 보기 모달에서 복호화된 값을 표시하도록 수정
