# 20260225 - 사이드바 펼침 시 콘텐츠 영역 가로 탈출 수정

## 1. 사용자 요건 내용

### 요건 설명
왼쪽 사이드바가 펼쳐진 상태에서 오른쪽 메인 콘텐츠가 뷰포트 오른쪽으로 밀려 나가는(layout overflow) 현상이 있다. 사이드바를 접으면 콘텐츠가 정상 위치에 오는데, 사이드바 열림/닫힘과 관계없이 콘텐츠가 항상 뷰포트 안에 제자리를 유지해야 한다.

### 사용자 시나리오
1. 로그인 후 앱 메인 화면 진입
2. 왼쪽 사이드바가 **펼쳐진** 상태에서 각 메뉴(검색, 이력·승인, 통계 등)로 이동
3. **문제**: 메인 콘텐츠 영역이 오른쪽으로 탈출하여 가로 스크롤 또는 레이아웃 깨짐 발생
4. 사이드바를 접으면 콘텐츠가 정상 위치로 보임

### 기대 결과
- 사이드바가 **펼쳐진 상태**에서도 메인 콘텐츠가 뷰포트 안에만 표시되고 가로 탈출이 없다.
- 사이드바가 **접힌 상태**에서도 동일하게 정상 배치 유지.
- 전환 시 애니메이션은 유지해도 됨.

## 2. 설계

### 기술 설계

#### 문제 분석
- `App.js`에서 메인 영역에 `marginLeft: DRAWER_WIDTH_*`와 `width: calc(100vw - DRAWER_WIDTH_*)`를 동시에 사용하고 있음.
- MUI `Drawer variant="permanent"`는 `width`/`flexShrink: 0`로 이미 flex 레이아웃에서 공간을 차지함.
- 메인에 추가로 `marginLeft`를 주면, 실제로는 “사이드바 너비 + margin”만큼 왼쪽이 비고, 메인 너비는 `calc(100vw - drawer)`로 설정되어 전체 사용 너비가 `100vw`를 초과하여 오른쪽으로 탈출.

#### 해결 방안
- **메인 영역**: flex로 남은 공간만 차지하도록 하고, `marginLeft` 및 `width`/`maxWidth`의 `calc(100vw - ...)` 제거.
- 메인은 `flex: 1`, `minWidth: 0`, `overflowX: 'hidden'`, `boxSizing: 'border-box'`로 제한하여 항상 컨테이너 안에만 그리도록 함.
- **루트**: `maxWidth: '100vw'`, `overflowX: 'hidden'`으로 뷰포트를 넘지 않도록 보장.

### 변경 파일 목록

#### 프론트엔드
- `frontend/src/App.js`
  - 메인 `Box`: `marginLeft`, `width`, `maxWidth` 제거; `flex: 1`, `minWidth: 0`, `overflowX: 'hidden'` 유지/보강. 루트 `Box`에 `maxWidth: '100vw'`, `overflowX: 'hidden'` 추가.
